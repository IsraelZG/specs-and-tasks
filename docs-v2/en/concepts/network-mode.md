# network-mode (replaced)

The three-mode model (pure P2P, corporate, public) no longer exists. Every
active network has an identified logical authority.

Two topologies remain: `corporate` and `public-operated`. The regulatory
profile is orthogonal to the topology.

Current definition: `docs-v2/en/architecture/topology-and-authority.md`.
Decision: `docs-v2/en/adr/ADR-001-logical-authority.md`.
