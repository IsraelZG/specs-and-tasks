# genesis-state (history)

The GENESIS state marked the founding peer of a pure P2P network during
autonomous bootstrap, with the immutable `NETWORK_BIRTH` record.

The state no longer exists with the autonomous genesis. Network creation
is an act of the logical authority, recorded in the official graph.

Decision: `docs-v2/en/adr/ADR-001-logical-authority.md`.
