# modalidade-de-rede (substituído)

O modelo de três modalidades (P2P puro, corporativa, pública) deixou de
existir. Toda rede ativa tem uma autoridade lógica identificada.

Restam duas topologias: `corporate` e `public-operated`. O perfil
regulatório é ortogonal à topologia.

Definição corrente: `docs-v2/arquitetura/topologia-e-autoridade.md`.
Decisão: `docs-v2/adr/ADR-001-autoridade-logica.md`.
