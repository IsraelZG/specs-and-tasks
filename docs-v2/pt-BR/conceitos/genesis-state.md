# genesis-state (histórico)

O estado GENESIS marcava o peer fundador de uma rede P2P puro durante o
bootstrap autônomo, com o registro imutável `NETWORK_BIRTH`.

O estado deixou de existir junto com a gênese autônoma. A criação da rede é
um ato da autoridade lógica, registrado no grafo oficial.

Decisão: `docs-v2/adr/ADR-001-autoridade-logica.md`.
